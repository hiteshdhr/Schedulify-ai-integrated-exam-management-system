# 📅 Schedulify - AI Integrated Exam Management System

Schedulify is a comprehensive, AI-powered academic scheduling system built to simplify exam and study management for students and educators. Leveraging advanced AI, Schedulify automatically creates optimized study plans, manages deadlines, and detects scheduling conflicts—empowering users to maximize their productivity and stay ahead in their coursework.

---

## 🚀 Features

- **AI-Driven Scheduling:** Automatically generate personalized study plans and prioritize tasks based on deadlines, course load, and user preferences.
- **Dynamic Dashboard:** Modern, responsive interface built with React (Vite-powered) and TypeScript providing real-time updates and seamless interactions.
- **Task Management:** Create, update, and monitor academic tasks for efficient time management.
- **Conflict Detection:** Smart algorithms prevent overlapping sessions and keep your routine balanced.
- **Multi-User Support:** Scalable system architecture for both students and academic staff.
- **Data Persistence:** Robust backend supports MongoDB or PostgreSQL for reliability and scalability.

## ⚡ Getting Started

### Prerequisites

- Node.js (v16+ recommended)
- npm or yarn
- MongoDB or PostgreSQL database instance

### Installation

**Backend:**

```bash
cd Backend
npm install
# Setup environment variables (see .env.example if present)
npm start
```

**Frontend:**

```bash
cd frontend
npm install
npm run dev
```

Access the application at `http://localhost:5173` (or your configured port).
